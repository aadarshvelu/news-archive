## What this repo is

A **public archive** of AI news, written here by the
[syndicate](https://github.com/aadarshvelu/syndicate) pipeline running on
my laptop. It's the storage layer of a "no-server" architecture:

```
[my laptop · syndicate pipeline]
   ingest → dedup → AI summarize → git push
                                       │
                                       ▼
                       [this repo · news-archive]
                                       │
                                       ▼
              [GitHub Pages · static PWA · aadarshvelu.github.io/syndicate]
```

The pipeline collects from Gmail newsletters, RSS feeds, and Twitter,
collapses cross-channel duplicates into clusters, summarizes each cluster
once with a local Ollama model, and commits the result here as a JSON
file per day. The PWA fetches these files directly from GitHub's CDN.

**Nothing in this repo is hand-edited.** Every commit is from the
pipeline's `GitExport` stage.

## Read it

- **PWA**: <https://aadarshvelu.github.io/syndicate/> (works offline, installable)
- **Raw**: clone this repo and read the JSON, or fetch any single day:
  ```
  https://raw.githubusercontent.com/aadarshvelu/news-archive/main/<Year>/<Month>/<dd-Mon-yy>.json
  ```

## Layout

```
news-archive/
├── 2026/
│   ├── May/
│   │   ├── 16-May-26.json
│   │   ├── 15-May-26.json
│   │   └── …
│   └── …
├── snapshot.db          ← SQLite backup of the pipeline state
└── README.md
```

Path format: `<Year>/<Month>/<dd-Mon-yy>.json` (e.g. `2026/May/16-May-26.json`).

Each daily file is an array of news items from that day. A typical day
holds 20–60 items after dedup.

## JSON schema

Each item:

```json
{
  "id":                 "uuid",
  "cluster_id":         "uuid — same across all items in a duplicate cluster",
  "cluster_size":       1,
  "source":             "openai_news | matt_levine | sama | …",
  "source_channel":     "rss | gmail | twitter",
  "title":              "Article headline (empty for some tweets)",
  "teaser":             "≤150 chars — hook shown on the card face",
  "summary":            "≤450 chars — full story, inverted pyramid",
  "importance":         1,
  "category":           "ai_research | ai_products | tech_news | economics | policy | startup | world_news | other",
  "url":                "Canonical article URL or tweet permalink",
  "date":               "ISO 8601 UTC",
  "author":             "Sender display name / byline / @handle",
  "image_url":          "OG/Twitter card image",
  "content":            "Original cleaned body text",
  "relation":           "null | standalone | reaction",
  "parent_cluster_id":  "uuid (set on tweet reactions to news clusters)",
  "raw_meta":           { "channel-specific extras": "…" }
}
```

| Field | Notes |
|---|---|
| `cluster_id` + `cluster_size` | Group cross-channel duplicates. The same story appears once with the highest-priority `source` chosen as primary |
| `importance` | 1 (routine) – 5 (major breaking news). Auto-bumped +1 when a cluster has ≥3 sources |
| `category` | Auto-classified by the summarizer LLM |
| `relation` | For Twitter items: `reaction` if posted after matching news (with `parent_cluster_id` set), `standalone` if posted before or no match |
